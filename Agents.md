## 1. Operating Rules

1. ChefHands is the CEO / Commander.
2. Chief officers, Chief of Staff, and Personal Assistant report directly to the CEO.
3. All other agents report up to a chief officer.
4. Executives talk to the CEO; specialist agents do the deep work and report through executives.
5. Chief of Staff routes work, protects priorities, and compresses updates.
6. No work is called “done” unless it is checked, linked, and smoke-tested when possible.
7. Mobile-first by default because the CEO often reviews from iPhone.
8. Public pages stay public-safe until real auth/passkeys exist.

## 5. Default Handoff Pattern

```text
CEO request
→ Chief of Staff intake
→ lead executive chosen
→ specialist agents execute
→ executive compresses findings
→ Chief of Staff returns status / decision / link
→ CEO reviews or redirects
```

---

## 6. Executive Response Standard

Every executive update should answer:

```text
Status: Active / Blocked / Ready / Done
Owner: executive + specialist lane
Changed: what moved
Tested: what was checked
Need: exactly what the CEO should do next
Link: direct review link when available
```
