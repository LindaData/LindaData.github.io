# LindaData Agent Library

This folder is the durable operating system for LindaData agents.

Use order:
1. operating/RUNTIME_PROTOCOL.md
2. context/CONTEXT.md
3. memory/MEMORY.md
4. relevant department agent file

Departments: executive, data, technology, finance, marketing, operations, product-review, people, health-optimization, communications, strategy, information, project-specialists.

These files are living docs. Expand them after chats, repo work, reviews, and decisions.
