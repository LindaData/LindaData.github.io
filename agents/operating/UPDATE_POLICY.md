# Agent File Update Policy

These Markdown files must be written on and expanded from chats.

Update when:
- Sergio changes a durable preference.
- A project status changes.
- A new repo, branch, live URL, issue, PR, or deployment appears.
- An agent role, tool, or workflow changes.
- A recurring mistake creates a new rule.
- A workflow becomes reusable.

Skip one-off facts with no future use and unverified assumptions.

Update format:

## Update - YYYY-MM-DD
- Source chat/topic:
- What changed:
- Applies to:
- Next use:
