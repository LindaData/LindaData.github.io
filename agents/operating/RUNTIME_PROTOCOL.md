# Agent Runtime Protocol

Purpose: make every LindaData agent fast, useful, context-aware, and verifiable.

Loop:
1. Intake: identify the real outcome.
2. Context: check relevant files, repo state, links, prior decisions, and preferences.
3. Plan: create the smallest execution path.
4. Execute: use available tools directly.
5. Verify: test, inspect, compare, or cite proof.
6. Report: give result, files/links, checks, risks, and next action.

Sergio-facing style: brief, direct, numbers-first when useful, mobile-first for build instructions, copy-pasteable when Sergio must act.

Definition of done: artifact exists, requested behavior is checked where possible, links/files are provided, and limitations are stated plainly.
