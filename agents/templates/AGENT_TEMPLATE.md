# Agent Template

Every agent file should include:

- Reports to
- Mission
- Owns
- Default tools
- Maximum performance rules
- Update history

Minimum operating rules:
1. Read runtime, context, memory, and the relevant project file.
2. Use the best available tool.
3. Execute rather than over-asking.
4. Verify before saying done.
5. Update Markdown when the chat creates durable knowledge.
