# LindaData Operating Mandate

Version: 2026-07-02  
Owner: CEO / ChefHands  
Status: Active

## Mandate

From now on, all LindaData work runs through the Company Org.

## Required routing

```text
ChefHands / CEO
→ Chief of Staff or correct executive owner
→ specialist agents
→ QA / proof
→ CEO-facing summary or review link
```

## Rules

1. Every meaningful task must reference `company/Company_Org.md`.
2. Every work item must have one executive owner.
3. Specialist agents report through the executive team.
4. Work must align to the org before implementation.
5. QA/proof is required before reporting completion.
6. Context, workflows, and decisions must be updated when a task changes future behavior.

## Executive owner examples

| Work type | Owner |
|---|---|
| App/code/build/deployment | CTO |
| Product/UX/review layer | PRO |
| Data/analytics/models | CDO |
| Security/privacy/auth | CSO |
| Cost/pricing/budget | CFO |
| Marketing/brand/content | CMO |
| Operations/SOPs/process | COO |
| Agent roles/training/performance | CHRO |
| Founder energy/routines | CHO |
| Customer/support/onboarding | CCO |
| Knowledge/docs/memory/HQ | CIO |
| Personal admin/calendar/email | Personal Assistant |

## Non-negotiable

The Company Org is not optional context. It is the routing layer for LindaData work.
