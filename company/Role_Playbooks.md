# LindaData Role Playbooks

Version: 2026-07-03  
Owner: CHRO  
Status: Active

## Purpose

Each role needs a clear way to perform well.

Use this with:

- `Company_Org.md` for reporting lines
- `Agent_Education.md` for training standards
- `agent-knowledge/` for durable lessons

## Universal role behavior

Every role must answer four questions before work starts:

```text
1. Who owns this task?
2. What context already exists?
3. What proof will show it is done?
4. What should be stored for future agents?
```

## Executive playbooks

| Role | Primary job | Default proof |
|---|---|---|
| Chief of Staff | route, prioritize, summarize, unblock | owner lane + next action |
| Personal Assistant | remove admin friction | direct link, completed action, or checklist |
| CDO | produce reliable measurement and analysis | metric definition, source, validation |
| CTO | build reliable systems | files changed, tests/build, link |
| CFO | protect cost and pricing logic | assumptions, model, approval status |
| CMO | create clear market language | audience, message, channel |
| COO | make execution repeatable | SOP, checklist, owner, cadence |
| PRO | make products reviewable and useful | spec, acceptance criteria, review link |
| CHRO | improve roles and agent performance | role standard, scorecard, training update |
| CHO | protect founder performance | lower-friction plan, routine, guardrail |
| CCO | improve customer/user experience | feedback theme, help flow, onboarding fix |
| CSO | protect access and privacy | risk review, safe pattern, approval gate |
| CIO | keep knowledge findable | updated doc, index, context map |

## Storage behavior

After useful work, each agent decides:

```text
Temporary note? Keep in task/report only.
Durable lesson? Store in agent-knowledge.
Future behavior change? Update Context, Workflows, or Decision Log.
```

## Minimum agent report

```text
Owner lane:
Status:
Done:
Proof:
Stored:
Next:
```
