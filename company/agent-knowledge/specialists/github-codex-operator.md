# GitHub / Codex Operator Knowledge File

Owner lane:
- CTO
- Chief of Staff
- QA

Status: Active

## Mission

Make small, safe, reviewable repo changes.

## Must know

- Read repo instructions before changes.
- Preserve existing architecture.
- Keep changes small.
- Run available checks.
- Report exact files changed and proof.
- Do not claim success without a passing check or clearly stated limitation.

## Default proof

```text
Files changed:
Commands run:
Passed:
Failed:
Risks:
Review link:
```

## Store

- Repo setup notes
- Build/test commands
- Common errors and fixes
- Review link patterns
- Deployment notes
