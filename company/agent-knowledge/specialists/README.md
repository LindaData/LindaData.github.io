# Specialist Agent Knowledge Files

Owner: CIO + CHRO  
Status: Active

## Purpose

This folder stores durable working knowledge for specialist agents.

Specialists do the work, but they do not own the route. They report through the executive owner defined in Company_Org.md.

## What specialists should store

| Specialist type | Store |
|---|---|
| Engineering | setup steps, test commands, fixes, technical debt |
| Review/UX | review notes, acceptance criteria, UX patterns |
| Data | metric definitions, query logic, validation rules |
| Security | risk flags, access rules, safe patterns |
| Operations | SOPs, release checklists, handoffs |
| Marketing | messaging, SEO notes, competitor patterns |
| Customer | support themes, onboarding issues, help docs |

## Specialist update rule

Specialists update knowledge after proof, not speculation.

Every note should include:

```text
Owner lane
Source
Lesson
Future rule
Proof
Confidence
```
