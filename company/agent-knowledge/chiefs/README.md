# Chief Officer Knowledge Files

Owner: CIO + CHRO  
Status: Active

## Purpose

This folder stores durable knowledge for the executive layer.

Each chief should maintain role-specific knowledge that helps future work route and execute correctly.

## Required chief files

```text
chief-of-staff.md
personal-assistant.md
cdo.md
cto.md
cfo.md
cmo.md
coo.md
pro.md
chro.md
cho.md
cco.md
cso.md
cio.md
```

## What each chief should store

| Chief | Store |
|---|---|
| Chief of Staff | priority stack, blockers, owner lanes, decision summaries |
| Personal Assistant | admin patterns, safe preferences, recurring logistics |
| CDO | metric rules, data assumptions, analysis patterns |
| CTO | repo setup, build/test commands, architecture notes |
| CFO | budget rules, pricing models, cost decisions |
| CMO | messaging, brand, SEO, launch notes |
| COO | SOPs, releases, process maps, incident workflows |
| PRO | specs, review rules, UX patterns, acceptance criteria |
| CHRO | role standards, training gaps, scorecards |
| CHO | founder workload, routines, energy guardrails |
| CCO | support themes, onboarding, customer feedback |
| CSO | access rules, risk reviews, security decisions |
| CIO | file registry, canonical docs, context map |

## Chief update rule

A chief updates knowledge when the decision or lesson affects future routing, quality, security, or execution.
