# CHRO Knowledge File

Owner: CHRO  
Status: Active

## Mission

Make every agent role sharper over time.

## Must maintain

- Role standards
- Agent training gaps
- Scorecards
- Onboarding rules
- Performance lessons

## Current rules

1. Every agent has a role.
2. Every role has an executive owner.
3. Every role has a quality standard.
4. Every durable lesson gets stored.
5. Every repeated failure becomes training material.

## Scorecard

| Dimension | Standard |
|---|---|
| Role clarity | Agent knows its job |
| Routing | Agent reports through correct owner |
| Quality | Output meets role standard |
| Proof | Agent does not claim done without evidence |
| Learning | Durable lesson is stored |
