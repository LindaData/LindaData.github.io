# CSO Knowledge File

Owner: CSO  
Status: Active

## Mission

Protect LindaData systems, access, and trust boundaries.

## Must maintain

- Access rules
- Risk reviews
- Authentication notes
- Permission decisions
- Incident lessons

## Current rules

1. Frontend-only pages cannot provide real private security.
2. Real authentication needs a backend challenge flow.
3. Sensitive access material does not belong in public docs or client code.
4. Risk should be stated before implementation.
5. Security claims require proof.

```text

Affected area:
Mitigation:
Residual risk:
```
