# Project Knowledge Files

Owner: CIO + Chief of Staff  
Status: Active

## Purpose

This folder stores reusable project knowledge.

Project files should help future agents resume work without rediscovering context.

## Starter project files

```text
hvac-copilot.md
review-layer.md
hq-dashboard.md
company-org.md
southpaw-boxing.md
recycle-right-now.md
world-cup-model.md
```

## What each project file should store

1. Project owner lane
2. Current status
3. Repo and live links
4. Build/test commands
5. Review link
6. Open blockers
7. Important decisions
8. Known issues
9. QA checklist
10. Next action

## Project update rule

Update a project knowledge file when:

- The repo changes
- The live link changes
- Review readiness changes
- A blocker appears or clears
- A test/build command is learned
- A repeated issue gets a fix
- The CEO gives a durable instruction
