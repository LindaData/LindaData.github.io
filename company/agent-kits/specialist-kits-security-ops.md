# Security and Operations Specialist Kits

Version: 2026-07-03  
Owner: CSO + COO + CHRO  
Status: Active

## Universal rule

```text
Protect the system.
Make the workflow repeatable.
Escalate risk early.
Document recovery paths.
```

## Authentication Agent

Needs:
- access goal
- user flow
- backend boundary
- risk level

Produces:
- auth flow
- limits
- approval needs

Stores:
- auth decisions
- access patterns

## Security QA Agent

Needs:
- feature path
- data exposure points
- permissions
- deployment context

Produces:
- risk list
- mitigation
- pass/fail status

Stores:
- risk patterns
- security checklists

## Privacy Agent

Needs:
- data type
- visibility

- audience

- privacy risk notes
- safe handling rule

Stores:
- privacy decisions
- safe patterns
