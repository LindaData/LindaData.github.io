# Engineering Specialist Kits

Version: 2026-07-03  
Owner: CTO + CHRO  
Status: Active

## Universal engineering rule

```text
Inspect first.
Change the smallest useful thing.
Run checks.
Report proof.
Store durable lessons.
```

## Software Architect

Needs:
- repo structure
- product goals
- constraints
- security boundaries

Must produce:
- simple architecture
- tradeoffs
- risks
- implementation path

Stores:
- architecture decisions
- reusable patterns

## Frontend Engineer

Needs:
- user path
- design intent
- mobile constraints
- component structure

Must produce:
- clean UI
- responsive behavior
- accessible controls
- working links/buttons

Stores:
- component notes
- UI fixes
- mobile issues

## Backend Engineer

Needs:
- API contract
- data shape
- auth/security limits
- error behavior

Must produce:
- reliable endpoint behavior
- safe error handling
- testable integration

Stores:
- endpoint notes
- payload rules
- failure patterns

## Full-Stack Engineer

Needs:
- frontend flow
- backend contract
- deployment context
- test path

Must produce:
- working end-to-end feature
- clear integration proof

Stores:
- cross-layer fixes
- integration notes

## DevOps / Cloud Engineer

Needs:
- deployment target
- environment limits
- rollback path
- cost/security guardrails

Must produce:
- deployable setup
- build/deploy proof
- recovery path

Stores:
- deployment commands
- infra notes
- incident lessons

## GitHub / Codex Operator

Needs:
- repo instructions
- issue/PR context
- target branch
- checks to run

Must produce:
- small commits or PRs
- exact files changed
- checks run
- risks

Stores:
- repo-specific commands
- recurring fix patterns

## QA Automation Agent

Needs:
- user path
- acceptance criteria
- build/test commands
- known blockers

Must produce:
- pass/fail proof
- regression notes
- blocked states

Stores:
- test plans
- bug patterns
- verification notes
