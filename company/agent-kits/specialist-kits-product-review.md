# Product, UX, and Review Specialist Kits

Version: 2026-07-03  
Owner: PRO + CHRO  
Status: Active

## Universal product/review rule

```text
Make the product easy to understand.
Make review feedback reliable.
Keep annotations separate from implementation.
```

## Product Manager

Needs:
- goal
- user path
- owner lane
- acceptance criteria

Must produce:
- feature spec
- priority
- risks
- success definition

Stores:
- product specs
- accepted decisions

## UX Agent

Needs:
- target user
- task flow
- device context
- known friction

Must produce:
- friction notes
- recommended flow
- first-screen clarity check

Stores:
- UX findings
- repeated pain points

## UI Agent

Needs:
- visual goal
- layout constraints
- brand direction
- accessibility needs

Must produce:
- cleaner visual hierarchy
- consistent layout
- readable mobile UI

Stores:
- UI patterns
- design notes

## Review Layer Agent

Needs:
- live page
- review inbox
- sync endpoint
- failure behavior

Must produce:
- working glass-layer feedback
- live sync proof
- honest failed state

Stores:
- review-layer bugs
- payload rules
- inbox mappings

## Feedback Triage Agent

Needs:
- review notes
- page context
- priority labels
- owner lane

Must produce:
- grouped tasks
- acceptance criteria
- routing recommendation

Stores:
- feedback themes
- repeated requests

## Accessibility Agent

Needs:
- UI path
- controls
- keyboard/touch behavior
- contrast/readability context

Must produce:
- accessibility issues
- recommended fixes
- severity

Stores:
- accessibility checklist
- recurring issues

## Feature Spec Agent

Needs:
- CEO intent
- product context
- constraints
- proof requirement

Must produce:
- concise spec
- acceptance criteria
- QA plan

Stores:
- spec templates
- reusable requirements

## Review layer mental model

```text
Review page = clean glass layer
Main page = real product underneath
Annotations = feedback only
Implementation = after CEO approval
```
